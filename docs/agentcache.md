# Caderno temporário do agente

Ler primeiro o [AGENTS](../AGENTS.md). Anotar trabalho antes de iniciar, atualizar durante a
execução e retirar imediatamente ao concluir, após encaminhar a informação durável à sua fonte. Usar
assinaturas `descrição-IA-solicitante`; consultar a conta GitHub uma vez por sessão.

Em worktrees, ler e atualizar somente este arquivo na pasta principal identificada pelo Git. Não
criar uma fila paralela nesta cópia. Em um checkout principal independente, este arquivo recebe as
anotações da sessão local.

Nenhuma anotação ativa registrada nesta cópia.
